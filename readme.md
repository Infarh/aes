# AES File Encryptor

Консольная утилита на .NET 10 для шифрования и расшифровки файлов.

## Что делает проект

- Шифрует файл и создает рядом новый файл с расширением `.aes`
- Расшифровывает файл `.aes` обратно в исходный файл
- Проверяет целостность зашифрованного файла перед расшифровкой
- Может обрабатывать несколько файлов за один запуск
- Показывает прогресс копирования в консоли

## Как работает

Программа принимает пути к файлам через аргументы командной строки.

- Если файл не имеет расширение `.aes`, выполняется шифрование
- Если файл имеет расширение `.aes`, выполняется расшифровка

Пароль не вводится отдельно: он вычисляется из имени файла.

- Для шифрования: имя файла без последнего расширения
- Для расшифровки: имя файла без двух последних расширений (например, `report.pdf.aes` -> `report`)

## Криптография

- KDF: PBKDF2 (SHA-512)
- Итерации PBKDF2: `210000`
- Шифрование: AES-256 (ключ 32 байта, IV 16 байт)
- Контроль целостности: HMAC-SHA256

Из PBKDF2 выводятся три значения:

- ключ AES (32 байта)
- IV AES (16 байт)
- ключ HMAC (32 байта)

## Формат зашифрованного файла

Файл `.aes` имеет следующий бинарный формат:

- `Magic` (4 байта): ASCII-строка `AES1`
- `Salt` (16 байт): случайная соль для PBKDF2, уникальная для каждого файла
- `Ciphertext` (N байт): зашифрованные данные
- `HMAC` (32 байта): HMAC-SHA256 по префиксу `Magic + Salt + Ciphertext`

Проверка при расшифровке выполняется в таком порядке:

- валидация минимального размера файла
- проверка сигнатуры `AES1`
- проверка HMAC в постоянное время
- только после этого расшифровка данных

## Совместимость формата

Текущая версия использует новый формат с заголовком и HMAC.

- Старые `.aes` файлы из предыдущей версии (без `Magic/Salt/HMAC`) не поддерживаются
- Для старых файлов потребуется отдельный режим миграции/совместимости

## Требования

- .NET SDK 10+
- Windows/Linux/macOS (для запуска через `dotnet`)

## Сборка

Из корня репозитория:

```bash
dotnet build FileEncryptor.Console/FileEncryptor.Console.csproj -c Release
```

## Запуск

### Вариант 1: через dotnet run

```bash
dotnet run --project FileEncryptor.Console -- "C:\data\report.pdf"
```

```bash
dotnet run --project FileEncryptor.Console -- "C:\data\report.pdf.aes"
```

Несколько файлов сразу:

```bash
dotnet run --project FileEncryptor.Console -- "C:\data\a.txt" "C:\data\b.jpg" "C:\data\c.zip"
```

### Вариант 2: после публикации

```bat
cd FileEncryptor.Console
release.bat
```

После публикации исполняемый файл будет в папке `.Release`.

Пример запуска опубликованной версии:

```bat
FileEncryptor.Console.exe "C:\data\report.pdf"
FileEncryptor.Console.exe "C:\data\report.pdf.aes"
```

## Поведение и ошибки

- Если файл не найден, выводится `File not found: <path>`
- Ошибки формата выводятся как `Format error ...`
- Криптографические ошибки (неверный пароль/повреждение/подмена) выводятся как `Cryptographic error ...`
- Если в ходе обработки были ошибки, приложение завершится с кодом `1`

## Примеры сценариев

### Шифрование

Вход: `photo.png`

Команда:

```bash
dotnet run --project FileEncryptor.Console -- "photo.png"
```

Результат: создается `photo.png.aes`

### Расшифровка

Вход: `photo.png.aes`

Команда:

```bash
dotnet run --project FileEncryptor.Console -- "photo.png.aes"
```

Результат: создается `photo.png`

## Структура проекта

- `FileEncryptor.Console/Program.cs` - точка входа и обработка аргументов
- `FileEncryptor.Console/FileInfoEx.cs` - шифрование/расшифровка, заголовок и HMAC
- `FileEncryptor.Console/AesEx.cs` - создание криптопотоков AES
- `FileEncryptor.Console/StreamEx.cs` - копирование потоков с прогрессом
- `FileEncryptor.Console/Constants.cs` - криптографические параметры и константы формата
